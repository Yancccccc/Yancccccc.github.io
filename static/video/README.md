# Turntable comparison assets

The project page expects 12 synchronized animated WebP files:

- `acrimsat_{gt,1p5k,30k}.webp`
- `desdyni_{gt,1p5k,30k}.webp`
- `hinode_{gt,1p5k,30k}.webp`
- `sacc_{gt,1p5k,30k}.webp`

Each scene uses one shared normalization, camera trajectory, frame count, white background, and rendering resolution so that the draggable comparison remains geometrically aligned.
